'/users' to get users with index from 1 to 1000.
'/users?offset=number(e.g 3)&limit=number(e.g 10)' to limit the number of users and offset the users.
'/users/id/somenumber(e.g 50)' to get users by their id, user can still apply limit and offset.
There are other fields like first_name,
last_name,
email,
favorite_color,
favorite_city,
ip_address,
favorite_plant,
employer that you can search by.
